# Personal Portfolio Website

This repository contains the source code for my personal portfolio website.

The website is a static frontend project built using HTML, CSS, and JavaScript. It is organised into separate pages and shared assets to keep the site simple to maintain and update.

## Technologies

- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## Project Structure

```text
.
├── .vscode/
├── images/
├── about.html
├── contact.html
├── index.html
├── projects.html
├── script.js
└── style.css
```

## Pages

- `index.html` — Homepage
- `about.html` — About and skills information
- `projects.html` — Projects and project details
- `contact.html` — Contact page

## Styling

`style.css` contains the shared styling for the website, including layouts, typography, navigation, buttons, responsive behaviour, and other reusable components.

Responsive layouts are implemented using CSS media queries to support different screen sizes.

## JavaScript

`script.js` contains the client-side functionality and interactive behaviour used throughout the website.

## Running Locally

No build tools or backend services are required.

The website can be run by opening `index.html` directly in a browser.

Alternatively, the project can be opened in Visual Studio Code and served using a local development server such as the Live Server extension.

## Updating the Website

Content and functionality can be updated through the relevant files:

- Homepage → `index.html`
- About information → `about.html`
- Projects → `projects.html`
- Contact information → `contact.html`
- Styling and layouts → `style.css`
- Interactive functionality → `script.js`
- Images and other assets → `images/`

## Future Work

Planned improvements to the portfolio include:

- Updating the projects section as new projects are completed.
- Adding further project details and links to their respective repositories.
- Potentially migrating the website from static HTML pages to React to improve component reuse, maintainability, and scalability as the portfolio grows.

## Repository Purpose

This repository contains the source code used to develop and maintain my personal portfolio website. It is separate from the repositories containing the individual projects showcased on the site.
